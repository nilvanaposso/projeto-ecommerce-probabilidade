# Projeto E-commerce e Probabilidade com Python

## Objetivo
Aplicar conceitos de Teoria da Probabilidade para analisar e prever comportamentos em um cenário de e-commerce.

## Conceitos Utilizados
- Probabilidade
- Variáveis Aleatórias
- Distribuição de Poisson
- Distribuição Exponencial
- Distribuição Normal
- Regra Empírica

## Tecnologias
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib

## Como Executar

1. Clone o repositório

```bash
git clone https://github.com/nilvanaposso/projeto-ecommerce-probabilidade.git
```

2. Instale as bibliotecas

```bash
pip install pandas numpy matplotlib
```

3. Abra o notebook

```bash
jupyter notebook
```
