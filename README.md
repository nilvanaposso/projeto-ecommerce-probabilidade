# E-commerce e Probabilidade com Python

## Descrição

Este projeto foi desenvolvido com o objetivo de aplicar conceitos de Teoria da Probabilidade em um contexto de e-commerce, utilizando Python para explorar fundamentos estatísticos importantes para análise de dados e tomada de decisão.

## Objetivos

* Compreender conceitos fundamentais de probabilidade.
* Aplicar distribuições estatísticas em cenários de negócio.
* Utilizar Python para análise e simulação de dados.
* Desenvolver habilidades práticas em análise de dados.

## Conceitos Abordados

### Teoria da Probabilidade

Estudo de eventos aleatórios e cálculo de probabilidades.

### Distribuição de Poisson

Utilizada para modelar a ocorrência de eventos em um intervalo de tempo ou espaço.

### Distribuição Exponencial

Utilizada para modelar o tempo entre ocorrências de eventos.

### Distribuição Normal

Uma das distribuições mais importantes da estatística, amplamente utilizada em análise de dados.

### Regra Empírica

Aplicação da distribuição normal para interpretação de dados dentro dos desvios padrão.
